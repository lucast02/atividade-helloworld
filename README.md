Este é meu projeto inicial desenvolvido para a atividade da disciplina.

O objetivo do projeto é criar um código simples utilizando HTML e disponibilizá-lo em um repositório público no GitHub.

O projeto possui o arquivo:

- `HelloWorld.html`

## Funcionamento

O arquivo `HelloWorld.html` apresenta uma página simples contendo uma mensagem de "Hello World!" e uma breve descrição.
